# snap-station
A modern recreation of the Pokemon Snap Station

> **Looking for the kiosk?** The full Snap Station v4 kiosk app (design-system UI, fault-safe
> credits, supplies tracking, dye-sub print ritual, 409-test suite) lives on the
> [`kiosk-v4`](../../tree/kiosk-v4) branch. `main` is intentionally pinned to the simple
> playground that GitHub Pages serves. To ship v4 live, merge `kiosk-v4` into `main`.

> **`/v5/`** — the "fable pass" demo: the station rebuilt as a game UI (Pokémon
> HOME-style BOX, pause-menu navigation, dialog boxes, Poké Mart print counter).
> Zero frameworks, zero build, boots instantly. Open `v5/` on the live site.
